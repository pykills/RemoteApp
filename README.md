# 🖥️ RemoteApp

A simple Windows desktop application launcher built with Python and Tkinter.

RemoteApp provides a clean, dark interface for quickly launching your favorite applications, games and Windows tools.

## ✨ Features

- 🎵 Launch Spotify
- 💬 Launch Discord
- 🎮 Launch Roblox
- 🎮 Launch Steam
- ⛏️ Launch Explorer
- 🌐 Launch Google Chrome
- 📝 Launch Notepad
- 🧮 Launch Calculator
- 💻 Open Windows Terminal
- ⚡ Run Terminal as Administrator
- 🔵 Open PowerShell
- ⚡ Run PowerShell as Administrator
- 🔎 Custom "Program Not Found" error window
- 📜 Scrollable application list
- 🖥️ Simple dark UI inspired by terminal / hacker-style interfaces

## 🛠️ Requirements

- Windows 10 / 11
- Python 3.x
- Tkinter

Tkinter is included with most standard Python installations on Windows.

## 🚀 Running RemoteApp

Clone the repository:

```bash
git clone https://github.com/pykills/RemoteApp.git

Go into the project folder:

cd RemoteApp

Run the application:

python remoteapp.py
